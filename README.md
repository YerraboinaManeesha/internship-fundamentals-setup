# Hello World - Internship Fundamentals Setup

## About the Project

This project was created as part of my internship Fundamentals and Setup phase. It is a simple Hello World web project developed to verify my development environment and practice basic web development and Git/GitHub workflow.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Features

* Displays a Hello World welcome message
* Responsive basic web page structure
* Styled using CSS
* Interactive button using JavaScript
* Displays a success message when the button is clicked

## Project Structure

```text
internship-fundamentals-setup/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Click the **Click Me** button to test the JavaScript functionality.

## Git and GitHub

This project was managed using Git for version control and uploaded to GitHub for repository management and sharing.

## Purpose

The purpose of this project is to verify the development environment and demonstrate basic knowledge of web development fundamentals, project structure, version control, and GitHub.
